Note: On CPU the two are close. Tiled avoids the large O(S^2) score
allocation, so it is competitive (often a touch faster) at small/medium
S, and falls behind only at large S where the Python per-tile loop
overhead dominates NumPy's single fused matmul. On CPU the dependable
win is MEMORY (section 3); the SPEED win needs the CUDA kernel keeping
tiles in shared memory (run on Colab to populate the CUDA GPU column).
