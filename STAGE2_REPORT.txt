────────────────────────────────────────────────────────────────────────────────
1. CUDA KERNEL IMPLEMENTATION (18 Kernels)
────────────────────────────────────────────────────────────────────────────────

I wrote 18 custom CUDA kernels in C++/CUDA to accelerate neural network operations:

Core Operations:
  • element_wise_multiply.cu    - Hadamard product for chain rule
  • element_wise_divide.cu      - Normalization gradients  
  • element_wise_subtract.cu    - Gradient computations
  • scalar_multiply.cu          - Learning rate scaling
  • exp.cu, log.cu             - Exponential and logarithm
  • transpose.cu               - Matrix transposition with shared memory

Activation Functions:
  • relu_forward/backward.cu   - ReLU activation and gradients
  • gelu_forward/backward.cu   - GELU activation and gradients

Normalization:
  • reduce_mean.cu             - Mean reduction along axes
  • reduce_variance.cu         - Variance computation
  • bias_add.cu               - Bias addition with broadcasting

Loss & Optimization:
  • cross_entropy_forward.cu   - Numerically stable cross entropy
  • cross_entropy_backward.cu  - Softmax-cross entropy gradient
  • sgd_update.cu             - SGD parameter updates
  • adam_update.cu            - Adam optimizer with momentum

All kernels were compiled with nvcc and exposed to Python via pybind11.

────────────────────────────────────────────────────────────────────────────────
2. AUTOGRAD ENGINE
────────────────────────────────────────────────────────────────────────────────

I implemented a PyTorch-style automatic differentiation engine:

Tensor Class Features:
  ✓ Dynamic computation graph construction
  ✓ Topological sort for backward pass
  ✓ Gradient accumulation and tracking
  ✓ Operations: +, -, *, /, @, sum, mean, sqrt, power
  ✓ Broadcasting support for element-wise operations
  ✓ no_grad() context manager for inference

The backward() method automatically computes gradients through the entire
computation graph using the chain rule.
